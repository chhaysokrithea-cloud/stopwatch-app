# ⏱️ Stopwatch App

A clean and simple stopwatch built with pure HTML, CSS, and JavaScript.

## 🚀 Features

- Start, Stop, and Reset functionality
- Displays hours, minutes, seconds, and milliseconds
- Minimal and responsive design

## 🛠️ Built With

- HTML
- CSS
- JavaScript (Vanilla)
